Jenny Wang portfolio — deploy on Netlify (free)
1. Go to https://app.netlify.com/drop and sign up / log in.
2. Drag this whole folder (jenny-portfolio) onto the page. The site goes live in seconds.
3. Site settings > Change site name > type: jennywangportfolio
   Your address becomes https://jennywangportfolio.netlify.app (if the name is free).
To update later: Deploys > drag the updated folder again.
